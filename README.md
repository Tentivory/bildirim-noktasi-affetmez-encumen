# Bildirim Noktası Affetmez Encümeni

> Silinmez. Okunmuş sayılmaz. Sadece kızarır.

Bu depo, telefonunuzun köşesindeki kırmızı noktanın hukuki kişiliğini tanır. Nokta vatandaş değildir. Nokta encümen üyesidir. Encümen üyesi affetmez.

Market uygulaması 1 yazmıştır. Siz açmamışsınızdır. Encümen bunu *kasten okunmamışlık* sayar. Cezası: utancınızın rakama çevrilmesi.

## Neden var

Çünkü birileri “her şeyi okudum” dedi. Yalan söyledi. Rozet hâlâ oradaydı. Bu yazılım o yalanı tutanağa çevirir. Isıtmaz, taşımaz, çözmez. Sadece karar verir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Encümen dış paket kabul etmez; dış paket de bir bildirimdir.

```bash
python3 encumen.py --uygulama Market --okunmamis 4 --uygulama AileGrubu --okunmamis 128 --uygulama Banka --okunmamis 1
```

Etkileşimli duruşma:

```bash
python3 encumen.py
```

Çıktı: karar, utancı puanı, silme yasağı ve bir satır mühür. Gerçekten çalışır. Nokta gerçekten silinmez; çünkü bu program telefonunuza ulaşmaz, sadece vicdanınıza ulaşır.

## Encümen içtihadı

| Okunmamış | Hüküm |
|---:|---|
| 0 | Şüpheli temizlik. Gizli sekme aranır. |
| 1 | Tek kişilik isyan. Affedilmez. |
| 2-9 | Klasik erteleme. Puan çarpanlıdır. |
| 10-99 | Toplu görmezden gelme. Dosya kabarır. |
| 100+ | Anayasal kriz. Rozet artık gezegendir. |
